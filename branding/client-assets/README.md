# Client-supplied TYBalls.ie logo

`TYBalls.ie-client-logo-original.JPG` is the exact logo artwork supplied by the client on 2026-08-03. It must remain unchanged.

The files under `public/brand/` are technical web exports from that original:

- `tyballs-client-logo-sign.*` — a lossless-content crop around the central sign for the compact website header;
- `tyballs-client-logo-full.*` — the complete supplied artwork for the footer and larger brand placements.

No generative model, typography replacement or visual redraw is used in either published version.
